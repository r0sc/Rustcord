All builds are 64-bit. Release notes are on GitHub. To build from source, see the README.

First start on Windows

The setup isn’t code-signed, so SmartScreen may say “Windows protected your PC”. Select More info, then Run anyway. It installs for your user only.

First start on macOS

Drag Rustcord to Applications and open it. macOS blocks it once because it isn’t notarized: click Open Anyway in System Settings, Privacy & Security. Or run:

xattr -dr com.apple.quarantine /Applications/Rustcord.app

After an update, macOS may ask again for the microphone and the keychain.

Install on Linux

Needs x86-64 and glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36). Runs on X11 or XWayland. On Debian, Ubuntu and Mint:

sudo apt install ./rustcord_<version>_amd64.deb

Anywhere else, for your user only:

tar -xzf rustcord-<version>-linux-x86_64.tar.gz
sh rustcord-<version>/install.sh
Updates and checksums

Rustcord asks GitHub for a new version every 6 hours and only installs updates signed with its Ed25519 key. GitHub sees your IP address and the app version. The check sends no other data.

To check a download, compare it with the release’s SHA256SUMS file:

sha256sum -c SHA256SUMS --ignore-missing

On Windows, use Get-FileHash. On macOS, use shasum -a 256.
