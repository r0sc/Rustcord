A look inside

How light it is

Rustcord draws its own interface with egui and runs its network code on tokio. There’s no Electron and no bundled browser.

What it does

The layout follows Discord’s web app, so you’ll know your way around. The look, the icons and the code are Rustcord’s own.

Chat

Markdown, mentions, custom emoji, replies and reactions. Edit and delete your own messages, upload files by drag and drop or paste, search, pin and mark unread. Threads and forum channels work too.

Voice and video

Voice channels and calls with DAVE end-to-end encryption, and you can watch anyone’s stream. Camera and screen sharing work on Windows for now. On Windows, a game overlay shows who’s talking.

Pictures and videos

Uploaded MP4 videos play right in the chat, decoded by Rustcord itself. Pictures, GIFs and videos open in a viewer with zoom, pan, Save, Copy image and Copy link.

Themes and your look

Nightshade, Lilac and High Contrast, plus a live editor for your own themes, saved as TOML files you can import and export. Add a banner and an animated avatar that only you see.

Profiles and activities

Profiles show avatar decorations, nameplates, effects, badges and connections from Discord. Games and Spotify appear with their art. Rustcord can detect the game you’re playing; others see it only if you turn on sharing.

Sign-in and account

Sign in with a QR code, with email and password (with 2FA), or with a token. Your session token is kept in your system’s credential store, never in a file. Account security, settings and server administration are built in.

On your desktop

A tray icon, start at sign-in and desktop notifications on Windows, Linux and macOS. The second start shows your cached servers right away. Installed copies update themselves, and updates are signed.

Not included

Account creation, slash commands and bot components, the sticker picker, other Nitro features and completing quests for you. Rustcord never solves captchas: when Discord asks for one, you solve it yourself in the sign-in card on Windows and macOS.

Before you download

  • It’s a beta, and it was vibe-coded

    Almost all of Rustcord’s code was written with AI coding tools (Claude Code), not by hand. Many features have only been tested with offline demo data, and the Linux and macOS builds have had the least testing. If something breaks, please open an issue.

  • Your account is at risk

    Third-party clients that log in with a user account violate Discord’s Terms of Service and can get the account banned. You use Rustcord at your own risk. It behaves like a normal user client (no automation, nothing is sent on your behalf, all rate limits are respected), but that doesn’t remove the risk.

  • It’s unofficial

    Rustcord is not affiliated with Discord. Its logo, look and icons are its own; it doesn’t use Discord’s logo, wordmark or brand colours.

Install notes

First start on Windows

The setup isn’t code-signed, so Windows SmartScreen may say “Windows protected your PC”. Select More info, then Run anyway. Rustcord installs for your Windows user only, without administrator rights. It starts hidden in the notification area when you sign in; you can turn that off in its settings.

First start on macOS
  1. Open the disk image and drag Rustcord onto Applications.
  2. Open Rustcord. macOS blocks it the first time, because Apple hasn’t notarized it.
  3. Go to System Settings, Privacy & Security, and click Open Anyway next to the Rustcord message.

On macOS 14 and older, you can also right-click Rustcord in Applications and choose Open. Or run this in Terminal:

xattr -dr com.apple.quarantine /Applications/Rustcord.app

The app is only ad-hoc signed, so macOS may ask again for the microphone and the keychain after an update.

Install on Linux

Both packages need 64-bit x86 and glibc 2.35 or newer (Ubuntu 22.04+, Debian 12+, Fedora 36+). On Debian, Ubuntu and Mint:

sudo apt install ./rustcord_<version>_amd64.deb

On any distribution, installed for your user only:

tar -xzf rustcord-<version>-linux-x86_64.tar.gz
sh rustcord-<version>/install.sh

Rustcord runs on X11, or through XWayland on Wayland desktops. The tray icon needs a desktop with a StatusNotifierItem tray, like KDE, Xfce, Cinnamon or Ubuntu’s GNOME.

Updates come from GitHub

To update itself, Rustcord asks GitHub for the newest version every 6 hours. GitHub sees your IP address and the app’s version; no Discord token or other personal data is sent.

Check a download

Every release has a SHA256SUMS file. Compare your download with it:

Windows (PowerShell)

Get-FileHash Rustcord-Setup-<version>.exe

Linux

sha256sum -c SHA256SUMS --ignore-missing

macOS

shasum -a 256 <file>

Updates are signed with Ed25519, and Rustcord checks the signature before it trusts anything in the update feed.
